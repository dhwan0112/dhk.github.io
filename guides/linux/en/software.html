How to read the install column

You do not need all of this. To start, a terminal, one editor and one viewer are enough. The install column means:

  • apt: sudo apt install NAME on Ubuntu and WSL
  • brew: brew install NAME with Homebrew on macOS; GUI apps use brew install --cask NAME
  • conda: conda install -c conda-forge NAME, which also works on clusters without admin rights
  • website: download the installer from the project's site

On a cluster you cannot use sudo. Check module avail first, and if the tool is not there, install it into your home directory with conda (chapter 09).

Version control

git records the history of changes to files. Keeping analysis scripts, job script templates and sets of input files in a git repository lets you answer "what settings did I use last month?". Leave large outputs and wavefunction files out of the repository. Most clusters have git; locally it is git in both apt and brew.
