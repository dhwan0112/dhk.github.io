Keyboard

KeyAction
Tabcomplete commands and file names; press twice for the list of candidates
↑ / ↓previous / next command
Ctrl-Cstop the running command
Ctrl-Dend of input; at an empty prompt, exit the shell (logs you out of ssh)
Ctrl-Zpause the running command; fg resumes it, bg continues it in the background
Ctrl-Rsearch command history; press again for older matches
Ctrl-Lclear the screen (clear)
Ctrl-A / Ctrl-Estart / end of line
Ctrl-Udelete everything before the cursor
!!repeat the last command, as in sudo !!
!$last argument of the previous command
historylist past commands; !NUMBER reruns one

Navigation and files

CommandAction
pwdcurrent directory
ls -lhlong listing with readable sizes; -a includes hidden files, -t sorts by modification time
cd PATHchange directory; cd alone goes home, cd .. up, cd - back to the previous one
mkdir -p a/b/ccreate nested directories in one go
cp a b, cp -r dir1 dir2copy; directories need -r
mv a bmove or rename
rm FILE, rm -r dirdelete; there is no recycle bin
*.out, h2o_?.xyzwildcards: * any number of characters, ? exactly one
find . -name '*.out'find by name, including subdirectories
du -sh *size of each item
df -hsize and free space per file system
tar czf a.tar.gz dir / tar xzf a.tar.gzbundle and compress / extract; tar tzf lists

Viewing and searching

CommandAction
less h2o.outpage through a file; /word searches, n next match, G end, q quit
head -n 20 / tail -n 20first / last 20 lines
tail -f h2o.outfollow a growing output; Ctrl-C stops
grep 'FINAL SINGLE POINT' *.outlines matching a pattern; -n line numbers, -i ignore case, -r recursive, -c count
wc -lcount lines
cmd | lesssend output to another command (pipe)
cmd > f, cmd >> fwrite output to a file (overwrite / append)
cmd 2>&1send errors to the same place
nano fedit; Ctrl-O saves, Ctrl-X exits
vim fedit; i to insert, then Esc and :wq to save and quit, :q! to quit without saving

Permissions

CommandAction

chmod 700 dironly you can enter (~/.ssh)
chmod -R g+r dirgive the group read access, recursively
