Linux
스타터팩

계산화학을 시작하면 첫 주 안에 검은 터미널 창과 마주친다. 이 가이드는 그 창에서 길을 잃지 않을 만큼의 Linux를 다룬다. 터미널 준비, 파일과 권한, 원격 접속, 클러스터에 첫 작업을 올리는 데까지 간다.

대상 Linux와 계산화학 입문자 · 셸 bash · 환경 Windows(WSL) · macOS · Linux

이 가이드에 관하여

ORCA, Quantum ESPRESSO, LAMMPS 같은 프로그램은 대부분 Linux 클러스터에서 돈다. 입력 파일을 올리고, 작업을 제출하고, 끝난 출력을 받아 오는 일은 전부 터미널에서 한다. 명령어를 수백 개 외울 필요는 없다. 매일 쓰는 것은 스무 개 남짓이고, 나머지는 필요할 때 찾아보면 된다.

각 장은 앞 장을 안다고 가정하고 쓰였다. 처음이라면 01장부터 순서대로 읽고, 이미 터미널이 익숙하다면 06장(ssh)이나 09장(HPC)으로 바로 넘어가도 된다. 반복 작업을 스크립트로 묶는 법은 셸 스크립팅 가이드에 따로 정리했다.
