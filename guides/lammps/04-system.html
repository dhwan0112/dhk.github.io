4.1 매뉴얼이 제시하는 세 가지 방법

LAMMPS 매뉴얼은 박스와 원자를 만드는 방법으로 다음 세 가지를 든다.

방법 핵심 명령 어떤 경우에
데이터 파일에서 읽기 read_data 분자 시스템, 토폴로지가 복잡한 경우
재시작 파일에서 읽기 read_restart 이전 시뮬레이션에서 이어 가는 경우
격자에서 만들기 lattice → region → create_box → create_atoms 결정, 슬랩, 단순 액체

한 입력에서 두 가지 이상을 섞어 써도 된다. 예컨대 금속 슬랩은 격자에서 만들고, 그 위에 흡착할 분자는 데이터 파일에서 읽는 식이다.

4.2 격자에서 만들기

가장 간단하게는 lattice 명령으로 결정 격자를 정의하고 그 위에 원자를 채운다.

units           lj
atom_style      atomic

lattice         fcc 0.8442
region          box block 0 10 0 10 0 10
create_box      1 box
create_atoms    1 box

mass            1 1.0

각 줄의 의미:

  • lattice fcc 0.8442: fcc 격자, 환원 밀도 0.8442 (LJ 단위계)
  • region box block 0 10 0 10 0 10: box 라는 이름의 직육면체 영역, 격자 단위로 각 축 0~10
  • create_box 1 box: 위 region 안에 원자 타입 1개를 위한 박스 생성
  • create_atoms 1 box: 타입 1 원자로 채우기

격자 종류로는 fcc, bcc, hcp, sc(단순입방), diamond, custom 등이 있다. region 은 block(직육면체) 말고도 sphere, cylinder, prism (비직교 박스용) 등을 지원한다.

격자 상수 단위

units real 이나 units metal 에서는 격자 상수를 Å 단위로 직접 준다.

units           metal
atom_style      atomic

lattice         fcc 3.615        # Cu 격자 상수 (Å)
region          slab block 0 8 0 8 0 6
create_box      1 slab
create_atoms    1 slab

mass            1 63.546

units lj 에서는 격자 상수 자리에 "환원 밀도"가 들어간다는 점이 다르다.

4.3 데이터 파일에서 읽기

분자 시스템처럼 토폴로지(결합, 각도, 이면각)가 복잡하면 외부 도구로 데이터 파일을 만든 뒤 read_data 로 읽어 들이는 편이 훨씬 편하다.

units           real
atom_style      full

read_data       system.data

데이터 파일은 텍스트이고, 다음과 같은 헤더와 섹션으로 이루어진다.

  • 헤더에는 박스 크기, 원자/결합/각도/이면각 개수와 종류 수가 들어간다.
  • Atoms 섹션의 형식은 atom_style 에 따라 다르다. full 이라면 atom-ID molecule-ID type charge x y z 순서다.
  • 토폴로지를 쓴다면 Bonds, Angles, Dihedrals, Impropers 섹션도 차례대로.

데이터 파일을 손으로 직접 쓰는 일은 드물고, 보통은 다음 도구로 만든다.

  • VMD + TopoTools (가장 흔함)
  • OpenBabel / Avogadro
  • moltemplate (지정한 분자 템플릿을 LAMMPS 입력으로 변환)
  • MDAnalysis / ASE 등 Python 라이브러리

4.4 경계 조건과 박스 모양

boundary 명령은 세 축의 경계 조건을 정한다.

boundary        p p p     # 3D 주기적 (기본)
boundary        p p f     # x, y는 주기적; z는 고정 (슬랩에 흔함)
boundary        f f f     # 클러스터 (모든 면 비주기)
  • p: 주기적(periodic)
  • f: 고정(fixed). 원자가 이 면을 넘으면 사라진다("lost atom" 오류).
  • s: 축소형(shrink-wrapped). 박스가 원자를 따라 줄어든다.
  • m: minimum shrink-wrapped. s + 최소 박스 크기 보장.

슬랩 시뮬레이션(표면 흡착, 박막 등)에서는 보통 p p f 나 p p m 조합을 쓴다. 이때 장범위 정전기에는 슬랩 보정(kspace_modify slab)이 함께 필요할 수 있다.

박스가 비직교(triclinic)라면 lattice 명령 옵션이나 region prism, 또는 read_data 헤더의 xy xz yz 항목으로 기울기를 정의한다.

4.5 시스템 만들기의 흔한 패턴

패턴 A: 단순 액체

units           lj
atom_style      atomic
lattice         fcc 0.8442
region          box block 0 10 0 10 0 10
create_box      1 box
create_atoms    1 box
mass            1 1.0

패턴 B: 결정 슬랩 + 진공

units           metal
atom_style      atomic
boundary        p p f

lattice         fcc 3.615
region          slab block 0 8 0 8 0 6
create_box      1 slab
create_atoms    1 slab
mass            1 63.546

# 위쪽에 진공 영역 추가 (change_box)
change_box      all z final 0.0 60.0

패턴 C: 분자 시스템

units           real
atom_style      full

read_data       system.data
include         ff_opls.in   # 힘장 정의는 별도 파일에

응용 단계에서는 패턴 B와 C를 합쳐 "결정 슬랩 + 그 위의 분자 시스템"을 만들게 된다. 자세한 내용은 Cu 응용 시리즈에 있다.
