조건문과 반복문

형식메모
if 명령; then ...; elif ...; else ...; fi명령의 종료 코드가 0이면 참
A && B / A || BA가 성공하면 B / 실패하면 B
for f in *.xyz; do ...; done파일 반복. $(ls)는 쓰지 않는다
shopt -s nullglob맞는 파일이 없으면 빈 목록
for i in {1..10}, {01..10}숫자 범위. 변수는 못 쓴다
for (( i=0; i<n; i++ ))C 형식. 범위에 변수를 쓸 때
while read -r a b; do ...; done < list.txt파일을 한 줄씩. 파이프로 넘기면 변수가 밖에 안 남는다
done < <(find . -name '*.out')명령 출력을 한 줄씩 (프로세스 치환)
case $f in *.xyz) ... ;; *) ... ;; esac패턴별로 나누기
continue / break이번 차례 건너뛰기 / 반복 끝내기

grep · sed · awk

ORCA 출력에서 자주 쓰는 형태만 모았다. 자세한 설명은 05장과 06장에 있다.

명령하는 일
grep -n "FINAL SINGLE POINT ENERGY" water.out맞는 줄을 줄 번호와 함께
grep -c "FINAL SINGLE POINT ENERGY" water.out맞는 줄 수 (최적화 단계 수를 셀 때)
grep -A 10 "^VIBRATIONAL FREQUENCIES" water.out맞는 줄과 그 뒤 10줄
grep -B 2 "TERMINATED NORMALLY" water.out맞는 줄과 그 앞 2줄
grep -l "TERMINATED NORMALLY" */*.out맞는 줄이 있는 파일 이름만. -L은 없는 파일
grep -r --include='*.out' -l "TERMINATED NORMALLY" jobs디렉터리 아래를 재귀로
grep -q "..." f출력 없이 종료 코드만 (if 조건용)
sed -n '10,20p' water.out10–20번째 줄만
sed -n '/CARTESIAN COORDINATES (ANGSTROEM)/,+4p' water.out패턴부터 4줄 더
sed -i 's/nprocs 4/nprocs 8/' */*.inp파일 안에서 바꾸기. -i.bak이면 원본을 남긴다
sed '/^#/d' f#으로 시작하는 줄 지우기
awk '{print $5}'공백 기준 다섯째 열
awk '{print $NF}'마지막 열 (NF는 열 개수)
awk 'NR > 2 {print $1}' water.xyz셋째 줄부터 첫 열 (NR은 줄 번호)
awk -F, '{print $2}' data.csv쉼표로 나눈 둘째 열
awk '/FINAL SINGLE POINT ENERGY/ {e=$5} END {print e}' water.out마지막으로 맞은 줄의 값
awk '{s += $2} END {print s / NR}' f둘째 열 평균
awk -v x="$e" 'BEGIN {printf "%.2f\n", x * 627.509}'셸 변수로 소수 계산 (Hartree → kcal/mol)

PBS와 Slurm

PBS는 PBS Pro 기준이다. 클러스터마다 큐 이름, 메모리 단위, 기본값이 다르니 사이트 문서를 함께 본다. 작업 스크립트 전체 예는 07장, 배열은 08장에 있다.

할 일PBS ProSlurm
제출qsub job.pbssbatch job.sh
내 작업 보기qstat -u $USERsqueue -u $USER
작업 상세qstat -f <jobid>scontrol show job <jobid>
끝난 작업 기록qstat -x <jobid>sacct -j <jobid>
취소qdel <jobid>scancel <jobid>
대화형 작업qsub -I -l select=1:ncpus=4srun --pty -c 4 bash
작업 이름#PBS -N opt#SBATCH --job-name=opt (-J opt)
코어와 메모리#PBS -l select=1:ncpus=8:mem=16gb#SBATCH --ntasks=1
#SBATCH --cpus-per-task=8
#SBATCH --mem=16G
MPI 프로세스 8개 (ORCA %pal)#PBS -l select=1:ncpus=8:mpiprocs=8#SBATCH --ntasks=8
시간 제한#PBS -l walltime=24:00:00#SBATCH --time=24:00:00
큐 / 파티션#PBS -q normal#SBATCH --partition=normal
출력 파일#PBS -j oe (표준 오류를 출력에 합침)#SBATCH --output=%x-%j.out
작업 배열#PBS -J 1-10#SBATCH --array=1-10
배열 번호$PBS_ARRAY_INDEX$SLURM_ARRAY_TASK_ID
제출한 디렉터리$PBS_O_WORKDIR$SLURM_SUBMIT_DIR
작업 ID$PBS_JOBID$SLURM_JOB_ID
받은 코어 수$NCPUS$SLURM_CPUS_PER_TASK, $SLURM_NTASKS
같은 글자, 다른 뜻

PBS의 -N은 작업 이름이지만 Slurm의 -N은 노드 수다. PBS의 -J는 배열이지만 Slurm의 -J는 작업 이름이다. 스크립트를 옮길 때는 한 글자 옵션보다 Slurm의 긴 옵션(--job-name, --nodes, --array)을 쓰면 헷갈리지 않는다.

PBS 작업은 홈 디렉터리에서 시작하므로 스크립트 첫머리에 cd "$PBS_O_WORKDIR"가 필요하다. Slurm은 제출한 디렉터리에서 시작한다. 작업 스크립트를 로컬에서 시험할 때는 cd "${PBS_O_WORKDIR:-$PWD}"처럼 기본값을 주면 편하다.
