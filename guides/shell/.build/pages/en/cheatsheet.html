Same letter, different meaning

PBS -N is the job name, but Slurm -N is the number of nodes. PBS -J is an array, but Slurm -J is the job name. When porting scripts, Slurm's long options (--job-name, --nodes, --array) avoid the confusion.

PBS jobs start in your home directory, so the script needs cd "$PBS_O_WORKDIR" near the top. Slurm jobs start in the submission directory. To test a job script locally, cd "${PBS_O_WORKDIR:-$PWD}" gives it a fallback.
