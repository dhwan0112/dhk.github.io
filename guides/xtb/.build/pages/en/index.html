xtb · CREST
User Guide

The Grimme group's semiempirical program xtb and conformer search tool CREST, followed through on a single molecule: optimisation and frequencies, molecular dynamics, metadynamics, conformer ensembles and DFT re-ranking.

Version xtb 6.7 · CREST 3 · Example alanine dipeptide · Run on NUS HPC

About this guide

xtb is a command-line program for the GFN family of tight-binding methods. It is two to three orders of magnitude faster than DFT and gets organic geometries reasonably right, so it is used to narrow down candidates before expensive calculations and to run long dynamics. CREST builds conformer ensembles on top of xtb by repeating metadynamics and optimisation.

Calling xTB from inside ORCA is covered separately in chapter 16 of the ORCA guide. This guide is about using xtb and CREST directly. Both guides use the same example (alanine dipeptide in water), so the results can be compared.
