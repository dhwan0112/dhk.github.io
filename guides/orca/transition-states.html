전이 상태 탐색의 세 가지 길

ORCA에서 전이 상태(TS, saddle point)를 찾는 방법은 크게 세 갈래로 나뉩니다.

방법입력으로 필요한 것강점 / 약점
NEB-TS반응물 + 생성물 구조가장 강건. 초기 추정 없이도 작동. 다소 비쌈.
OptTSTS 초기 추정 구조 + 헤시안빠르지만 좋은 추정과 헤시안 필요. 발산 위험.
ScanTS반응 좌표 정의1차원 반응에서 자연스럽고 직관적.

NEB-TS — 첫 시도로 권장

NEB-TS는 Nudged Elastic Band 방법과 OptTS를 결합한 접근입니다. 반응물과 생성물 구조만 있으면 알아서 두 구조를 잇는 경로를 만들고, 그 위에서 가장 높은 점을 골라 정밀하게 TS로 수렴시킵니다.

다음은 아세트산 분자 내부 양성자 이동의 NEB-TS 입력 예입니다(매뉴얼 6.3.16절 예제).

# reactant.inp — 반응물 구조에서 시작
! XTB NEB-TS

%neb
   neb_end_xyzfile "product.xyz"    # 생성물 좌표 파일
end

* xyz 0 1
  C    0.416   0.039  -0.014
  C    0.042   0.012   1.440
  O    1.524   0.177  -0.454
  O   -0.654  -0.128  -0.804
  H   -0.391  -0.126  -1.737
  H   -0.913   0.507   1.585
  H   -0.058  -1.026   1.751
  H    0.820   0.485   2.030
*

product.xyz 파일에는 같은 분자의 “양성자가 다른 산소로 이동한” 구조의 좌표가 들어 있어야 합니다. 원자 순서가 반응물과 동일해야 한다는 점에 주의하시기 바랍니다.

NEB-TS의 결과는 다음과 같이 요약됩니다.

“CI”(Climbing Image)로 표시된 이미지가 수렴된 전이 상태이고, 그 옆의 dE 값(kcal/mol)이 활성화 에너지의 1차 추정치입니다. NEB-TS는 이 점을 추가로 OptTS로 정밀 수렴시키므로, 최종 결과는 출력 파일 끝부분의 FINAL SINGLE POINT ENERGY를 보시면 됩니다.

NEB의 여러 변형

매뉴얼에 정리된 변형들은 비용·강건성에서 약간씩 차이가 있습니다.

키워드특징
NEB표준 NEB. CI 없음. 경로만 얻습니다.
NEB-CIClimbing Image — 최고점을 정확히 잡아 줌. OptTS 단계 없음.
NEB-TSNEB-CI + OptTS. 가장 자주 사용.
Loose-NEB-TSNEB 단계 임계값 완화. 더 빠름, 다소 덜 정확.
Tight-NEB-TS임계값 강화. 정확하지만 비쌈.
Fast-NEB-TSIDPP만으로 초기 경로 생성. 가장 빠름.
ZOOM-NEB-TS경로 일부를 “확대”하여 재집중. 긴 꼬리가 있는 반응에 효과적.
속도가 우선이라면 GFN-XTB로 먼저

DFT로 직접 NEB-TS를 돌리면 시간이 오래 걸릴 수 있습니다. 먼저 ! XTB NEB-TS로 빠르게 대략적인 TS를 얻은 뒤, 그 구조를 초기 추정으로 삼아 ! B3LYP D4 def2-TZVP OptTS로 정밀 수렴시키는 2단계 전략이 권장됩니다. XTB는 ORCA에 내장된 매우 빠른 준경험적 방법입니다.

OptTS — 좋은 초기 추정이 있을 때

이미 TS에 가까운 초기 구조와 정밀한 헤시안이 있다면 OptTS가 가장 효율적입니다. 반드시 같은 메소드의 진동수 계산으로 헤시안을 먼저 만들어 두어야 합니다. 

# 1단계: 초기 추정 구조에서 헤시안 계산
! B3LYP D4 def2-SVP NumFreq
* xyzfile 0 1 ts_guess.xyz

$new_job

# 2단계: OptTS
! B3LYP D4 def2-SVP OptTS Freq
%geom
   InHess     Read
   InHessName "job1.hess"
   Calc_Hess  true          # 매 5 step마다 헤시안 재계산
   Recalc_Hess 5
end
* xyzfile 0 1
OptTS는 까다롭습니다

OptTS는 반드시 초기 구조가 TS와 같은 “골짜기”에 있어야 수렴합니다. 초기 헤시안에 정확히 하나의 음의 고유값이 있어야 하고, 그 모드가 반응 좌표를 가리키고 있어야 합니다. 확신이 없다면 처음부터 NEB-TS로 시작하시는 것이 안전합니다.

ScanTS — 스캔 + TS 검색 자동화

반응 좌표가 한 개의 결합 길이나 각도로 명확하다면 ScanTS가 직관적입니다. ORCA가 자동으로 표면을 스캔하면서 최대값을 지나면 그곳을 초기 추정으로 OptTS를 시작합니다. 

! B3LYP D4 def2-SVP ScanTS

%geom Scan
   B 2 5 = 2.5, 1.0, 16      # 2-5 결합을 2.5 → 1.0 Å로 스캔
end
end

* xyzfile 0 1 reactant.xyz

스캔이 최대를 지나는 순간 자동으로 OptTS로 전환됩니다. 매뉴얼은 스캔 중간 점에서 헤시안을 한 번 계산하여 정확도를 높이는 것을 권장합니다. ScanTS의 전체 스캔이 끝나기를 기다리고 싶다면 fullScan true를 추가합니다.

IRC — 전이 상태 검증

TS를 얻었다면 그것이 정말 의도한 반응을 잇는 TS인지 확인해야 합니다. IRC(Intrinsic Reaction Coordinate)는 TS에서 양쪽 방향으로 가장 가파른 내리막을 따라가 반응물과 생성물에 도달하는 경로를 추적합니다. 

! B3LYP D4 def2-SVP IRC

%irc
   MaxIter   100
   PrintLevel 1
   Direction  both    # forward / backward / both
   InitHess   read
   Hess_Filename "ts.hess"
end

* xyzfile 0 1 ts.xyz

IRC는 같은 입력 파일에서 !OptTS, !ScanTS, !NEB-TS, !AnFreq, !NumFreq와 함께 사용할 수 있어, “TS 검색 → 진동수 확인 → IRC”를 한 번에 끝낼 수도 있습니다. 

# NEB-TS → AnFreq → IRC를 한 번에
! B3LYP D4 def2-SVP NEB-TS AnFreq IRC

%neb
   neb_end_xyzfile "product.xyz"
end

* xyzfile 0 1 reactant.xyz

권장 워크플로우

새로운 반응의 TS를 찾을 때 다음 흐름을 권장합니다.

  1. 반응물·생성물 구조 최적화: 가벼운 방법(예: r2SCAN-3c 또는 XTB)으로.
  2. XTB-NEB-TS: 빠르게 대략적인 TS를 잡습니다. 보통 몇 분 안에 끝납니다.
  3. DFT OptTS: 위에서 얻은 TS 구조를 초기값으로 정밀 수렴. 헤시안은 함께 계산.
  4. AnFreq: 정확히 하나의 허수 진동수가 있는지 확인.
  5. IRC: 양방향 IRC로 반응물·생성물에 도달하는지 검증.
  6. 단일점 정밀화: 필요시 DLPNO-CCSD(T)/cc-pVTZ 등으로 최종 에너지를 다듬습니다.

이 워크플로우를 따르면 결과의 신뢰성이 크게 높아집니다. 특히 IRC를 빠뜨리면 “전이 상태처럼 보이지만 다른 반응을 잇는” 잘못된 TS를 발표하게 될 위험이 있습니다.

활성화 자유에너지 ΔG‡ 계산

반응의 활성화 자유에너지는 다음과 같이 구합니다.

ΔG‡ = G(TS) − G(반응물)

이때 G는 진동수 계산에서 얻은 “Final Gibbs free energy”입니다. 상태점 두 곳 모두 동일한 메소드·베이시스·온도에서 계산해야 비교가 의미가 있습니다.
