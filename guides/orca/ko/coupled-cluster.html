DLPNO-CCSD(T)

대규모 분자에서도 사용 가능한 황금 표준 계산. 화학 정확도를 합리적 비용으로.

이 페이지에서 다룹니다
  • 왜 DLPNO-CCSD(T)인가
  • 기본 사용법
  • 정밀도 단계 — Loose / Normal / Tight
  • 완전 베이시스 외삽 (CBS)
  • F12 — 베이시스 한계에 빠르게 접근
  • 열린 껍질 — UHF 레퍼런스
  • 권장 워크플로우
  • 한 걸음 더 — 다중참조 (CASSCF · NEVPT2)

왜 DLPNO-CCSD(T)인가

CCSD(T)는 단일참조 양자화학의 “황금 표준”입니다. 일반적인 닫힌 껍질 화학종에서 상대 에너지를 ±1 kcal/mol(이른바 화학 정확도) 이내로 재현합니다. 그러나 표준 CCSD(T)는 시스템 크기에 대해 O(N7)로 증가하므로, 원자 20개를 넘는 시스템에서는 비현실적으로 비싸집니다.

DLPNO(Domain-based Local Pair Natural Orbital) 근사는 이 비용을 획기적으로 줄여 줍니다. 국소 궤도와 도메인 기반 페어 자연 궤도를 사용해 점근적으로 선형 확장(linear scaling)을 달성하면서도, 기준 CCSD(T) 에너지의 약 99.9%를 재현합니다. 매뉴얼은 DLPNO-CCSD(T)를 “DLPNO-MP2가 가능하면 DLPNO-CCSD(T)도 가능하다”고 설명합니다. 실제로 원자 수백 개 규모의 분자에도 적용 가능합니다.

기본 사용법

키워드 라인에 DLPNO-CCSD(T)와 함께 보조 베이시스를 지정하면 됩니다.

# 닫힌 껍질 단일점 — 일반적인 정밀 에너지
! DLPNO-CCSD(T) cc-pVTZ cc-pVTZ/C TightSCF

* xyzfile 0 1 mol.xyz

보조 베이시스(/C 접미사)는 RI-MP2와 동일한 형식입니다. DLPNO-CCSD(T) 계산은 RI 적분이 필수이므로 반드시 함께 지정해야 합니다.

주 베이시스권장 보조 베이시스
cc-pVDZcc-pVDZ/C
cc-pVTZcc-pVTZ/C
cc-pVQZcc-pVQZ/C
def2-SVPdef2-SVP/C
def2-TZVPdef2-TZVP/C
def2-TZVPPdef2-TZVPP/C

정밀도 단계 — Loose / Normal / Tight

DLPNO의 컷오프 임계값은 세 단계로 단순화되어 있습니다.

키워드전형적 비용상대 정확도권장 사용처
LoosePNO0.5×약 95~98%대규모 스크리닝, 빠른 탐색.
NormalPNO1× (기본)약 99.5%일반 연구. 기본 추천.
TightPNO약 2~3×약 99.9%벤치마크, 발표 직전의 정밀 에너지.
 
# 벤치마크 수준 정확도
! DLPNO-CCSD(T) TightPNO cc-pVTZ cc-pVTZ/C TightSCF
상대 에너지 비교에서는 동일한 임계값을

반응 에너지나 결합 해리 에너지를 비교할 때는 모든 종에 같은 PNO 임계값을 적용해야 오류가 상쇄됩니다. 한 종은 NormalPNO로, 다른 종은 TightPNO로 계산하면 차이가 0.5 kcal/mol 정도 어긋날 수 있습니다.

완전 베이시스 외삽 (CBS)

CCSD(T)는 완전 베이시스 한계(CBS, Complete Basis Set limit)로 외삽할 때 가장 정확합니다. ORCA의 Extrapolate 키워드는 이를 자동화합니다. 

# cc-pVTZ와 cc-pVQZ로 CCSD(T) 단일점을 자동 외삽
! DLPNO-CCSD(T) Extrapolate(3/4, cc) TightSCF

* xyzfile 0 1 mol.xyz

Extrapolate(X/Y, basis) 형식입니다. X, Y는 베이시스의 카디널 수(2 = DZ, 3 = TZ, 4 = QZ, 5 = 5Z)이고, basis는 cc(Dunning), def2, aug-cc 등 베이시스 패밀리입니다.

입력실제 수행 작업
Extrapolate(2/3, cc)cc-pVDZ와 cc-pVTZ의 두 계산을 자동 외삽.
Extrapolate(3/4, cc)cc-pVTZ와 cc-pVQZ로 외삽. 가장 일반적.
Extrapolate(2/3, def2)def2-SVP와 def2-TZVPP로 외삽.
Extrapolate(3, cc)cc-pVDZ, cc-pVTZ, cc-pVQZ의 세 계산 + 두 쌍의 외삽.

EP2 · EP3 — 더 큰 베이시스를 위한 효율적 외삽

큰 베이시스(예: cc-pV5Z)에서 CCSD(T)를 직접 계산하기는 비싸지만, MP2 수준에서는 가능할 때가 많습니다. EP2/EP3 외삽은 “큰 베이시스의 MP2 + 작은 베이시스의 CCSD(T) − MP2 보정”을 결합해 효율을 높입니다. 

# EP2: 작은 기저에서 CC, 큰 기저에서 MP2 외삽
! DLPNO-CCSD(T) ExtrapolateEP2(2/3, cc) TightSCF

F12 — 베이시스 한계에 빠르게 접근

F12 명시적 상관 방법은 더 작은 베이시스로도 CBS 한계 근처의 정확도를 얻게 해 줍니다. DLPNO-CCSD(T)-F12는 이 두 기법의 결합입니다. 

# DLPNO-CCSD(T)-F12 with approach D — F12로 큰 베이시스 효과 대체
! DLPNO-CCSD(T)-F12D cc-pVDZ-F12 cc-pVDZ-F12-CABS cc-pVDZ-F12/C TightSCF

F12에는 전용 베이시스와 CABS(Complementary Auxiliary Basis Set)가 필요합니다. 베이시스 이름 끝의 -F12, -F12-CABS를 잊지 마시기 바랍니다. F12 방법을 사용하면 cc-pVDZ-F12 한 번의 계산이 cc-pVQZ 또는 cc-pV5Z CBS 외삽과 비슷한 정확도를 보입니다.

열린 껍질 — UHF 레퍼런스

라디칼이나 다중항 시스템에서는 UHF 레퍼런스를 사용한 “UHF-DLPNO-CCSD(T)”를 씁니다. 

! UHF DLPNO-CCSD(T) cc-pVTZ cc-pVTZ/C TightSCF

* xyz 0 2          # 도플렛 라디칼
  O   0.0   0.0   0.000
  H   0.0   0.0   0.969
*
스핀 오염 확인 필수

UHF 레퍼런스를 사용할 때는 SCF 결과의 ⟨S²⟩ 값을 반드시 확인하시기 바랍니다. 도플렛(S = 1/2)의 이상 ⟨S²⟩는 0.75이지만, 스핀 오염이 심하면 1.0 이상이 나오기도 합니다. 그러면 후속 CCSD(T) 결과도 신뢰하기 어렵습니다. 오염이 심하면 ROHF 레퍼런스를 시도하거나, 다중참조 방법(CASSCF/NEVPT2)을 고려하셔야 합니다.

권장 워크플로우

DLPNO-CCSD(T)는 대개 단일점 에너지로만 쓰입니다. 그래디언트도 구현되어 있지만 비싸기 때문에, 구조 최적화는 가벼운 방법(DFT)으로 하고 그 위에 정밀 에너지를 얹는 “composite” 워크플로우가 표준입니다.

  1. 구조 최적화 + 진동수: B3LYP-D4/def2-TZVP 또는 r2SCAN-3c로 수행. 깁스 보정 ΔGtherm 확보.
  2. DLPNO-CCSD(T) 단일점: 위 구조에서 CBS 외삽 또는 F12로 정밀 전자 에너지 EelecCC 산출.
  3. 용매 보정: 필요 시 (DFT/SMD) − (DFT/gas) 차이로 ΔGsolv 계산.
  4. 최종 자유에너지: Gfinal = EelecCC + ΔGthermDFT + ΔGsolv.

이 흐름의 입력 예시는 다음과 같습니다.

# Step 1: 구조 최적화 + 진동수 (DFT)
! B3LYP D4 def2-TZVP RIJCOSX def2/J TightOpt Freq
* xyzfile 0 1 mol.xyz

$new_job

# Step 2: DLPNO-CCSD(T) 정밀 단일점 (CBS 외삽)
! DLPNO-CCSD(T) Extrapolate(3/4, cc) TightSCF
* xyzfile 0 1

$new_job

# Step 3: 용매 효과 (SMD)
! B3LYP D4 def2-TZVP RIJCOSX def2/J CPCM(water) TightSCF
%cpcm
   SMD true
   SMDSolvent "water"
end
* xyzfile 0 1

반응 평형이나 자유에너지 장벽을 보고할 때 이 같은 “DFT 최적화 + CCSD(T) 정밀점 + SMD 용매” 조합은 오늘날 양자화학에서 가장 표준적인 절차이며, 학술지에서도 통상적으로 받아들여집니다.

DLPNO를 다른 메소드와 결합

DLPNO 근사는 CCSD(T) 외에도 CCSD, MP2, B2PLYP(이중 하이브리드)와 결합 가능합니다. 예컨대 ! DLPNO-B2PLYP D4 def2-TZVP def2-TZVP/C로 이중 하이브리드의 비용을 크게 낮출 수 있어, 중대형 분자의 정밀 단일점에 매우 유용합니다.

한 걸음 더 — 다중참조의 영역 (CASSCF · NEVPT2)

DLPNO-CCSD(T)는 단일참조(single-reference) 이론의 정점입니다. 한 개의 슬레이터 행렬식이 지배적인 시스템 — 닫힌 껍질 유기 분자, 일반적인 라디칼 — 에서는 거의 정량적으로 정확합니다. 그러나 다음과 같은 시스템에서는 단일참조 가정 자체가 깨집니다.

  • 전이금속·란타나이드 착물의 비공선 자기 상태 (예: Dy3 삼각자기 클러스터, 다핵 SMM)
  • 결합이 끊어지는 도중의 분자 (예: H2 해리, σ-결합 해리)
  • 단일항 디라디칼, 일부 들뜬 상태, 교차점 부근의 동역학

이 영역에서는 두 개 이상의 슬레이터 행렬식이 비슷한 가중치를 가지므로 명시적으로 여러 참조 상태(active space)를 동시에 풀어 주는 CASSCF가 시작점이 됩니다. 그리고 그 위에 동적 상관(dynamic correlation)을 얹는 표준 처리가 NEVPT2입니다.

입력의 뼈대 — %casscf 블록

# Dy(III) 4f9 단일 이온 — CASSCF(9,7) + NEVPT2 + SOC + 비등방성 추출
! CASSCF def2-SVP DKH2 RIJCOSX def2/J TightSCF

%casscf
   nel      9                # 활성 전자 수 (Dy 4f9)
   norb     7                # 활성 궤도 수 (7개 4f 궤도)
   mult     6, 4, 2          # 6중항(S=5/2) · 4중항(S=3/2) · 2중항(S=1/2)
   nroots   7, 35, 84        # Russell-Saunders 항 수 (Weyl 공식)
   PTMethod sc_nevpt2        # 동적 상관 보정

   rel
      DoSOC    true          # 2차 spin-orbit coupling (QDPT)
      SOCType  2             # SOMF 1X 연산자
   end

   SINGLE_ANISO true        # Pseudospin Hamiltonian 자동 fit
end

* xyz 3 6                  # Dy3+ 단일 이온 (전하 +3, 다중도 6은 GS 항)
   Dy   0.000   0.000   0.000
*

주요 키워드를 짧게 짚으면 다음과 같습니다.

키워드의미
nel · norb활성 공간(active space) 크기. CAS(n, m)에서 n과 m.
mult · nroots각 다중도에서 풀 상태 수. Dy3+는 4f9이므로 ⁶H 17/2 바닥 항 외에 다수의 중·고에너지 항을 모두 포함해야 합니다.
PTMethod sc_nevpt2strongly-contracted NEVPT2. 활성 공간 밖의 동적 상관을 섭동론으로 보정.
DoSOC true2차 spin-orbit coupling(QDPT)으로 SO-상태들을 얻음. 자기 특성에 필수.
SINGLE_ANISO trueSO-상태에서 자동으로 의사스핀(pseudospin) 1/2 Hamiltonian을 fit해 g-tensor와 에너지 갈라짐을 출력.
DKH2 / ZORA스칼라 상대론. 무거운 원소에서 거의 필수.
활성 공간 선택이 가장 어려운 부분

CASSCF의 결과는 활성 공간의 선택에 결정적으로 의존합니다. 자기특성 계산에서는 “해당 금속의 d 또는 f 궤도 전부 + 중요한 ligand 궤도”라는 화학적 직관에서 출발합니다. 너무 작으면 결과가 부정확하고, 너무 크면 비용이 폭증합니다. 처음 시도라면 활성 전자·궤도를 점진적으로 늘려 가며 결과의 수렴성을 보는 것이 정석입니다.

출력에서 무엇을 보는가

위 입력을 실행하면 출력의 거의 끝부분에 SINGLE_ANISO 의 결과가 표 형태로 나타납니다. 일반적으로 다음과 같은 정보를 우선 확인합니다. 

--------------------
PSEUDOSPIN HAMILTONIAN
--------------------
Pseudospin S = 1/2

ENERGIES OF DOUBLET STATES (cm**-1):
   doublet  1:      0.00
   doublet  2:    156.21
   doublet  3:    267.54
   ...

g-FACTORS OF THE LOWEST DOUBLET:
   gx =   0.04
   gy =   0.07
   gz =  19.74     <-- 큰 비등방성 → Ising-limit, 토로이드 가능성

gz가 매우 크고 gx, gy가 0에 가까우면 “Ising-limit 비등방성” 상태로, 단일분자 자석(SMM)의 가장 중요한 1차 진단입니다. 그 다음 단계는 POLY_ANISO로 여러 금속 중심 사이의 교환 상호작용 파라미터 J를 fit해 다핵 거동을 모사하는 것입니다 (매뉴얼 §9.27).

CASSCF 다음 가지들 — NEVPT2, MRCI, DMRG

동적 상관을 더 정확히 다루려면 PTMethod fic_nevpt2(fully internally contracted) 또는 ! MRCI+Q(다중참조 CI + Davidson 보정)로 옮겨갈 수 있습니다. 활성 공간이 12 궤도를 넘어가면 정통 CASSCF가 메모리 한계에 부딪히며, 그때부터는 ORCA 6의 DMRG-CASSCF(%casscf actorbs DMRG) 가 표준입니다. 본 가이드는 입문 분량이라 여기까지로 멈추지만, 키워드만 알아 두시면 매뉴얼 §9 와 §10 의 해당 절을 곧장 펼쳐 보실 수 있습니다.
