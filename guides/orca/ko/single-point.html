단일점 에너지

기본 예제 — HF, DFT

단일점 계산은 ORCA에서 가장 단순한 작업입니다. 메소드와 베이시스 세트, 그리고 좌표만 있으면 됩니다. 별도의 작업 유형 키워드를 적지 않으면 단일점이 기본값입니다.

HF 단일점

# CO 분자의 HF 단일점
! HF def2-SVP

* xyz 0 1
  C   0.0   0.0   0.0
  O   0.0   0.0   1.13
*

DFT (B3LYP) 단일점

# 사이클로헥산의 B3LYP/def2-TZVP 단일점
! B3LYP D4 def2-TZVP RIJCOSX def2/J TightSCF

* xyzfile 0 1 cyclohexane.xyz

RIJCOSX와 def2/J를 함께 지정한 것은 하이브리드 DFT의 사실상 표준 가속 조합입니다. 이 둘을 켜면 Coulomb 항은 RI로, 교환 항은 COSX(Chain-of-Spheres exchange)로 처리되어, 중대형 분자에서 한 자릿수 배 이상의 속도 향상을 얻을 수 있습니다.

RIJCOSX는 거의 무료입니다

매뉴얼에서 인용되는 벤치마크에 따르면 RIJCOSX의 에너지 오차는 정확한 적분에 비해 보통 마이크로 하트리(μEh) 수준이며, 대부분의 화학적 응용에서 무시할 수 있습니다. 하이브리드 DFT를 사용한다면 거의 무조건 RIJCOSX를 함께 켜시기를 권합니다.

원자별 베이시스 변경

전이금속 착물에서는 흔히 “금속에는 큰 베이시스, 리간드에는 작은 베이시스”를 쓰는 식의 혼합 전략이 유용합니다. ORCA는 이를 간결한 문법으로 지원합니다. 

# CuCl4 음이온 — Cu에 TZVPP, Cl에 DUNNING-DZP
! HF

%basis
   basis "SV"                          # 전 원자 기본 SV
   newGTO Cl "DUNNING-DZP" end      # Cl만 DUNNING-DZP로 교체
end

* xyz -2 2
  Cu   0.00   0.00   0.00   newGTO "TZVPP" end  # Cu만 TZVPP로 교체
  Cl   2.25   0.00   0.00
  Cl  -2.25   0.00   0.00
  Cl   0.00   2.25   0.00
  Cl   0.00  -2.25   0.00
*

이런 식으로 원자 단위·원소 단위로 베이시스를 자유롭게 섞을 수 있습니다. 유효 핵 포텐셜(ECP)도 같은 방식으로 지정할 수 있습니다.

열린 껍질 계산

홀수 전자 분자나 짝짓지 않은 전자가 있는 다중항 시스템에서는 비제한 스핀(UHF/UKS)을 명시적으로 지정하시는 것을 권장합니다. 

# OH 라디칼 (도플렛)
! UKS B3LYP D4 def2-TZVP TightSCF UNO

* xyz 0 2
  O   0.0   0.0   0.000
  H   0.0   0.0   0.969
*

UNO 키워드는 비제한 자연 궤도(Unrestricted Natural Orbitals)와 비제한 대응 궤도(UCO)를 출력합니다. 이는 스핀 오염도와 결합 다중성을 진단하는 데 매우 유용합니다. 출력에는 다음과 같은 표가 등장합니다. 

----------------------
Orbital    Overlap(*)
----------------------
...
101:      0.99563
102:      0.74329   <-- 1보다 한참 작음 → 스핀-커플 페어
103:      0.00000

오버랩이 1에 가까우면 이중 점유 궤도, 0이면 단일 점유, 그 사이의 값(보통 0.85 이하)이면 스핀-커플(예: 단일항 디라디칼)을 시사합니다. 이 정보 하나만으로 시스템의 전자 구조를 빠르게 진단할 수 있습니다.

출력 해석 — 주요 항목

출력 파일은 길지만, 가장 중요한 줄들은 몇 군데로 압축할 수 있습니다. DFT 단일점 계산의 출력에서 우선 확인할 부분은 다음과 같습니다.

SCF 수렴 후 후속 작업

단일점 계산 후 자주 이어지는 작업은 모집단 분석과 분자 궤도 시각화입니다. 모두 키워드 한두 개로 활성화할 수 있습니다.

모집단 분석

매뉴얼이 권장하는 조합은 다음과 같습니다.

! HF def2-SVP Mulliken Loewdin Mayer ReducedPOP

출력의 모집단 분석 부분은 다음과 같이 정리됩니다.

-----------------------
MULLIKEN ATOMIC CHARGES
-----------------------
   0 O :   -0.612345
   1 H :    0.306173
   2 H :    0.306173
Sum of atomic charges:   -0.0000000

-----------------------------------------
LOEWDIN ATOMIC CHARGES
-----------------------------------------
   0 O :   -0.487654
   1 H :    0.243827
   2 H :    0.243827

-----------------
MAYER POPULATION ANALYSIS
-----------------
   0 O :  Total valence: 2.012  Mean: 1.006  ...
...
   ATOM    ATOM     BOND ORDER
   0 O     1 H        0.987
   0 O     2 H        0.987
어떤 분석을 신뢰할 것인가

Mulliken 전하는 베이시스 세트에 매우 민감하여 큰 베이시스에서 발산하는 경향이 있습니다. Loewdin은 그보다 안정적이고, Mayer 결합 차수(bond order)는 화학적 직관과 잘 일치합니다. 본격적인 정량 분석에는 NPA(Natural Population Analysis)나 CHELPG를 사용하시기를 권합니다.

분자 궤도 시각화

분자 궤도를 입체적으로 보고 싶다면 %plots 블록으로 큐브 파일을 생성하거나, 별도의 orca_plot 유틸리티를 사용합니다.

방법 ①: 입력 안에서 직접 생성

! B3LYP def2-SVP TightSCF

%plots
   dim1  45
   dim2  45
   dim3  45
   Format Gaussian_Cube
   MO("homo.cube", 4, 0)    # 인덱스 4번 알파 MO
   MO("lumo.cube", 5, 0)
end

* xyzfile 0 1 water.xyz

방법 ②: 계산 후 orca_plot 사용

# 대화형 모드 - 메뉴를 따라 진행
orca_plot water.gbw -i

생성된 .cube 파일은 VMD, Avogadro, ChimeraX, PyMOL 등에서 시각화할 수 있습니다.

단일점 계산은 ORCA의 모든 작업의 출발점입니다. 이 페이지에서 다룬 출력 해석법은 다른 모든 계산 유형에도 그대로 적용됩니다. 다음 장에서는 구조를 풀어 가는 작업, 즉 구조 최적화로 넘어갑니다.
