NOTE 11-20-01 · 다항함수와 유리함수의 그래프 개형
{: .amm-id}

## 1. 일반 사항

### A. 목적

1. 이 노트는 다항함수와 유리함수의 개형을 다섯 가지 대수적 특성으로 결정하는 절차를 제시한다.
   1. 양 끝에서의 극한(ends).
   2. 영점과 중복도(zeros).
   3. 불연속점(breaks): 구멍과 수직 점근선.
   4. 절편(intercepts).
   5. 부호 변화(signs).
2. 이 노트는 개형에서 함수식을 재구성하는 역과정을 제시한다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
다섯 가지 특성이 모두 정해지면 곡선은 그 사이를 잇는 일만 남는다. 틀린 개형의 대부분은 특성 하나를 빠뜨린 데서 생긴다. 홀수 차수인데 양 끝 화살표를 같은 방향으로 그리는 경우, 중복도 2인 영점에서 축을 관통하는 경우, 약분되는 인수를 점근선으로 그리는 경우가 그 예다. 그래프에서 식을 세우는 문제는 다섯 가지 특성을 식의 인수로 되돌리는 일이다.
</div>

### B. 적용 범위

1. 실계수 다항함수와 유리함수에 적용한다.
2. 극값의 정확한 위치와 높이는 미분이 필요하므로 다루지 않는다(3.G 참고).

### C. 결과 요약

1. 예제 $$f(x) = \frac{x^3 - 4x^2 + x + 6}{x^3 - x^2 - 9x + 9}$$ 는 수평 점근선 $$y = 1$$, 영점 $$x = -1, 2$$, 구멍 $$(3, \tfrac13)$$, 수직 점근선 $$x = 1, -3$$, $$y$$ 절편 $$\tfrac23$$ 을 갖는다.
2. $$x = a$$ 에서 분모가 0일 때, 약분 후 분모에 $$x - a$$ 가 남으면 수직 점근선이고 남지 않으면 구멍이다.
3. 구멍과 점근선을 가르는 계산은 분자에 그 $$x$$ 를 넣었을 때 0이 되는지 여부다.
4. 그래프에서 식을 세우는 문제는 다섯 가지 특성을 역순으로 인수에 옮긴다. 조건이 식을 하나로 정하지 못할 수도 있다.

## 3. 절차

### A. 인수분해

1. 예제 함수를 정한다.

$$
f(x) = \frac{x^3 - 4x^2 + x + 6}{x^3 - x^2 - 9x + 9}
$$

2. 다섯 가지 특성을 구하기 전에 인수분해한다.
3. 분모를 묶는다. $$x^2(x-1) - 9(x-1) = (x-1)(x-3)(x+3)$$ 이다.
4. 분자에 $$x = -1$$ 을 넣으면 0이므로 $$x+1$$ 로 나눈다. 결과는 $$(x+1)(x-2)(x-3)$$ 이다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
이 나눗셈은 [조립제법 노트]({{ '/teaching/synthetic-division-and-horner-method/' | relative_url }})에서 따로 다룬다.
</div>

5. 약분한 식을 쓴다.

$$
f(x) = \frac{(x+1)(x-2)(x-3)}{(x-1)(x+3)(x-3)} = \frac{(x+1)(x-2)}{(x-1)(x+3)} \quad (x \neq 3)
$$

### B. 양 끝에서의 극한

1. 다항함수는 최고차항 하나로 양 끝에서의 극한을 정한다.
   1. 차수가 짝수면 양 끝이 같은 방향이다.
   2. 차수가 홀수면 양 끝이 반대 방향이다.
   3. 최고차계수의 부호가 오른쪽 끝의 방향이다.
2. 왼쪽 끝의 부호를 검산한다. 큰 음수를 최고차항에 넣었을 때의 부호다.

<div class="amm-warning" markdown="1">
<span class="amm-label">경고</span>
차수가 홀수인데 두 극한을 같은 부호로 적었다면 틀린 것이다.
</div>

3. 유리함수는 약분한 뒤 분자와 분모의 차수를 비교한다.
   1. 분자 차수가 작으면 $$y \to 0$$ 이다.
   2. 차수가 같으면 최고차계수의 비로 간다.
   3. 분자 차수가 하나 크면 나눗셈의 몫이 사선 점근선이 된다.
4. 예제에 적용한다. $$x^2/x^2$$ 이므로 $$x \to \pm\infty$$ 에서 $$f(x) \to 1$$ 이다.

### C. 영점과 중복도

1. 약분한 뒤의 분자에서 영점을 구한다. $$x = -1$$ 과 $$x = 2$$ 이고, 둘 다 중복도 1이다.

<div class="amm-warning" markdown="1">
<span class="amm-label">경고</span>
원래 분자에 있던 $$x = 3$$ 은 영점이 아니다. 그 점에서 분모도 0이라 함숫값이 없다.
</div>

2. 중복도로 영점 근처의 모양을 정한다. $$x = r$$ 근처에서 $$f(x) \approx C(x-r)^m$$ 이다.
   1. $$m$$ 이 홀수면 부호가 바뀌어 축을 관통(cross)한다.
   2. $$m$$ 이 짝수면 부호가 유지되어 축에 닿았다가 돌아간다(touch).
   3. 홀수라도 $$m \ge 3$$ 이면 $$y = x^3$$ 처럼 납작하게 눕듯이 지나간다.

### D. 불연속점: 구멍과 수직 점근선

1. 약분된 $$x - 3$$ 으로 구멍을 정한다.
2. 구멍의 좌표는 약분한 식에 넣어 구한다. $$\frac{(4)(1)}{(2)(6)} = \frac{1}{3}$$ 이므로 $$(3, \tfrac{1}{3})$$ 이다.
3. 남은 분모 $$(x-1)(x+3)$$ 에서 수직 점근선 $$x = 1$$, $$x = -3$$ 을 정한다.
4. 수평 점근선은 3.B 에서 구한 $$y = 1$$ 이다.
5. 곡선과 수평 점근선의 교점을 구한다.
   1. $$\frac{(x+1)(x-2)}{(x-1)(x+3)} = 1$$ 을 푼다.
   2. $$x^2 - x - 2 = x^2 + 2x - 3$$ 에서 $$x = \tfrac{1}{3}$$ 이다.
   3. 곡선은 $$(\tfrac{1}{3}, 1)$$ 에서 점근선을 가로지른다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
수평 점근선은 양 끝에서의 극한에 대한 조건일 뿐이다. 곡선이 가운데에서 이 선을 지나가도 된다.
</div>

### E. 절편

1. $$y$$ 절편을 구한다. $$f(0) = \frac{(1)(-2)}{(-1)(3)} = \frac{2}{3}$$ 이다.
2. 원래 식에 넣어 확인한다. $$\frac{6}{9}$$ 로 같다.
3. $$x$$ 절편은 3.C 의 영점 두 개다.

### F. 부호 변화

1. 수직선을 영점과 수직 점근선에서 자른다.

<div class="amm-warning" markdown="1">
<span class="amm-label">경고</span>
구멍은 부호표의 경계가 아니다. 약분한 식은 $$x = 3$$ 에서 연속이므로 양쪽의 부호가 같다.
</div>

2. 각 구간의 부호를 정한다.

| 구간 | $$(-\infty, -3)$$ | $$(-3, -1)$$ | $$(-1, 1)$$ | $$(1, 2)$$ | $$(2, \infty)$$ |
|---|---|---|---|---|---|
| $$f(x)$$의 부호 | + | − | + | − | + |

3. 부호표로 점근선 근처의 방향을 정한다.
   1. $$x = -3$$ 의 왼쪽은 양수라 $$+\infty$$ 로 가고, 오른쪽은 음수라 $$-\infty$$ 에서 올라온다.
   2. $$x = 1$$ 도 왼쪽 $$+\infty$$, 오른쪽 $$-\infty$$ 다.
   3. 두 점근선 모두 분모 인수의 지수가 1이라 양쪽 부호가 반대다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
$$\frac{2}{(x-3)^2}$$ 처럼 지수가 짝수면 분모가 양쪽에서 모두 양수다. 이 경우 곡선은 점근선 양쪽에서 같은 방향으로 간다.
</div>

### G. 다항함수에서 부호표로 관통과 접함 검산

1. 대상 함수를 정한다. $$f(x) = (x+2)(x-1)^2(x-3)$$ 이다.
2. 다섯 가지 특성을 구한다.
   1. 최고차항이 $$x^4$$ 이므로 양 끝이 모두 위로 간다.
   2. $$x = -2$$ 와 $$x = 3$$ 에서 관통하고, $$x = 1$$ 에서 접한다.
   3. $$f(0) = (2)(1)(-3) = -6$$ 이다.
3. 부호를 정한다. 네 구간에서 $$+, -, -, +$$ 이다.
4. 가운데 두 구간이 모두 음수임을 확인한다. $$(x-1)^2$$ 이 부호를 바꾸지 않기 때문이다.
5. $$x = 1$$ 에서 곡선이 아래에서 올라와 축에 닿고 다시 내려가도록 그린다.

<div class="amm-warning" markdown="1">
<span class="amm-label">경고</span>
$$x = 1$$ 에서 곡선이 축을 관통하게 그리면 부호표와 모순이 생긴다.
</div>

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
다섯 가지 특성이 정하지 않는 값도 있다. $$(-2, 1)$$ 에서 가장 낮은 점은 실제로 $$x \approx -1.15$$, $$f \approx -16.3$$ 이며, 미분을 해야 구해진다. 미분을 쓰지 않는 개형 분석의 목표는 위치 관계(어느 구간에서 축 위인지 아래인지, 어디서 닿고 어디서 관통하는지)이며, 극값의 정확한 높이는 포함하지 않는다.
</div>

### H. 약분되는 인수와 남는 인수의 판정

1. $$x = a$$ 에서 원래 분모가 0이면 $$a$$ 를 정의역에서 뺀다.
2. 약분을 끝까지 한 결과로 판정한다.
   1. $$x - a$$ 가 분모에 남으면 수직 점근선이다.
   2. 남지 않으면 약분된 식에 $$a$$ 를 넣은 자리에 구멍이다.
3. 같은 $$x$$ 에서 구멍과 수직 점근선이 동시에 생기지 않음을 확인한다. 약분의 결과는 하나이기 때문이다.
4. 정확한 판정은 인수의 소거가 아니라 분자와 분모의 중복도 비교로 한다.
   1. $$\frac{x-5}{(x-5)^2} = \frac{1}{x-5}$$ 는 분모 쪽 중복도가 더 크므로 점근선이다.
   2. $$\frac{(x-5)^2}{x-5} = x - 5$$ 는 분자 쪽 중복도가 더 크므로 구멍이다. 이 구멍은 $$(5, 0)$$ 으로 $$x$$ 축 위에 있다.

### I. 조건에 맞는 유리함수 구성

1. 구멍 $$(2, 1)$$, 수직 점근선 $$x = -4$$, 수평 점근선 $$y = 3$$ 을 갖는 유리함수를 구성한다.
   1. 먼저 약분된 모양을 정한다. 수평 점근선 3과 수직 점근선 $$-4$$ 에서 $$\frac{3(x - b)}{x + 4}$$ 꼴이다.
   2. 구멍의 높이가 1이 되도록 $$\frac{3(2 - b)}{6} = 1$$ 을 푼다. $$b = 0$$ 이다.
   3. $$\frac{x-2}{x-2}$$ 를 곱한다.

$$
f(x) = \frac{3x(x-2)}{(x-2)(x+4)}
$$

2. 결과를 확인한다. 약분되는 $$x - 2$$ 가 구멍을, 남는 $$x + 4$$ 가 점근선을 만든다.
3. 사선 점근선 $$y = 2x - 1$$ 과 수직 점근선 $$x = 3$$ 을 동시에 요구하는 함수를 $$\frac{(2x-1)(x-3) + k}{x - 3}$$ 꼴로 둔다.

<div class="amm-warning" markdown="1">
<span class="amm-label">경고</span>
$$k = 0$$ 이면 $$x - 3$$ 이 약분되어 그래프는 직선 $$y = 2x - 1$$ 에 구멍 하나가 뚫린 것이 된다. 요구한 점근선은 사라진다. 반드시 $$k \neq 0$$ 을 확인한다.
</div>

4. $$k = 5$$ 로 둔다. $$\frac{2x^2 - 7x + 8}{x - 3} = 2x - 1 + \frac{5}{x-3}$$ 이다.
5. 분자에 $$x = 3$$ 을 넣는다. $$18 - 21 + 8 = 5 \neq 0$$ 이므로 약분이 일어나지 않는다.

### J. 점근선에서 구멍으로의 극한 과정

1. 다음 함수족에서 $$\varepsilon$$ 을 0으로 줄인다.

$$
f_\varepsilon(x) = \frac{(x - 2 + \varepsilon)(x+1)}{(x-2)(x-3)} = \frac{x+1}{x-3} + \frac{\varepsilon(x+1)}{(x-2)(x-3)}
$$

2. $$\varepsilon \neq 0$$ 인 동안의 모양을 확인한다.
   1. $$x = 2$$ 는 수직 점근선이다.
   2. 영점 $$x = 2 - \varepsilon$$ 이 점근선 쪽으로 붙는다.
   3. 뒤쪽 항은 $$x = 2$$ 근처에서 약 $$-\frac{3\varepsilon}{x-2}$$ 이므로 곡선이 크게 튀는 구간의 폭이 $$\varepsilon$$ 에 비례해 줄어든다.
   4. $$\varepsilon = 0.01$$ 이면 그래프가 $$\lvert y \rvert \le 8$$ 창 밖으로 나가는 구간은 $$x = 2$$ 양쪽을 합쳐 폭 0.01 미만이다.
3. $$\varepsilon = 0$$ 에서 $$x - 2$$ 가 약분된다. $$\frac{x+1}{x-3}$$ 에 구멍 $$(2, -3)$$ 만 남는다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
영점과 점근선이 같은 자리에서 만나 서로 소거되고, 그 흔적으로 점 하나가 빠진다.
</div>

<figure>
<img src="{{ '/images/blog/sketch-graph-five-steps/asymptote_to_hole.gif' | relative_url }}" alt="As epsilon goes to 0, the zero at x = 2 - epsilon merges with the vertical asymptote x = 2 and leaves a hole at (2, -3)">
<figcaption>ε이 1에서 0.01로 줄어드는 동안 영점 x = 2 − ε이 점근선 x = 2에 붙고, 곡선이 튀는 구간이 가늘어진다. ε = 0에서 점근선이 사라지고 구멍 (2, −3)만 남는다.</figcaption>
</figure>

4. 함수족 $$f_k(x) = \frac{x^2 + k}{x - 1}$$ 에 같은 판정을 적용한다.
   1. 나누면 $$x + 1 + \frac{k+1}{x-1}$$ 이다. 나머지 $$k + 1$$ 은 나머지정리대로 분자에 $$x = 1$$ 을 넣은 값이다.
   2. $$k \neq -1$$ 이면 모두 같은 사선 점근선 $$y = x + 1$$ 과 수직 점근선 $$x = 1$$ 을 갖는다.
   3. $$k = -1$$ 일 때만 점근선 대신 직선 위의 구멍 $$(1, 2)$$ 가 된다.
5. $$\frac{x^2-4}{x-2}$$ 와 $$\frac{x^2+4}{x-2}$$ 를 비교한다.
   1. 앞의 함수는 구멍 $$(2, 4)$$ 가 뚫린 직선이다.
   2. 뒤의 함수는 $$x = 2$$ 에 점근선이 있는 곡선이다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
점근선인지 구멍인지를 가르는 계산은 분자에 그 $$x$$ 를 넣었을 때 0이 되는지 여부 하나다.
</div>

### K. 그래프에서 함수식 재구성

1. 다섯 가지 특성을 역순으로 인수에 옮긴다.
   1. 수직 점근선은 분모의 인수다.
   2. $$x$$ 절편은 분자의 인수다.
   3. 접하는 영점은 제곱 인수다.
   4. 구멍은 분자와 분모에 함께 넣는 인수다.
   5. 수평 점근선은 차수와 최고차계수의 비로 정한다.
2. 남는 상수 하나는 $$y$$ 절편으로 정한다.
3. 그래프 위의 다른 점 하나로 검산한다(4.A, 4.B).

### L. 조건이 충돌하거나 부족한 경우

1. "$$x = -2$$ 에서 접하고 $$x = 3$$ 에서 관통하며, 양 끝이 모두 내려가고, $$y$$ 절편이 음수"인 다항식을 구성한다.
   1. 영점 두 개만 쓴 $$-(x+2)^2(x-3)$$ 은 3차라서 양 끝이 반대 방향이 된다.
   2. 양 끝에서의 극한이 짝수 차수를 요구하므로 홀수 중복도의 영점이 하나 더 필요하다.
   3. $$-(x+2)^2(x-3)(x-c)$$ 로 둔다. $$f(0) = -12c$$ 이므로 $$y$$ 절편이 음수이려면 $$c > 0$$ 이다.
   4. $$c = 3$$ 이면 $$x = 3$$ 이 접하는 영점이 되므로 뺀다.
   5. $$c = 5$$ 를 고르면 $$f(0) = -60$$ 이다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
이 문제의 핵심은 그림이 아니라 영점 두 개로는 조건을 만족할 수 없음을 확인하는 데 있다.
</div>

2. 조건이 식을 하나로 정하지 못하는 경우를 확인한다.
   1. 수직 점근선 $$x = 2$$ 하나, 수평 점근선 $$y = 0$$, $$x$$ 절편 $$x = -1$$ 하나라는 조건을 둔다.
   2. 이 조건은 $$\frac{x+1}{(x-2)^2}$$ 과 $$\frac{-3(x+1)}{(x-2)^2}$$ 을 둘 다 허용한다.
   3. 세로 배율과 부호가 정해지지 않는다.
   4. 분모를 $$(x-2)^3$$ 으로 바꾸면 점근선 양쪽의 방향까지 바뀐다.

<div class="amm-note" markdown="1">
<span class="amm-label">참고</span>
함수식을 재구성하는 문제에서는 식 하나를 제시하는 것보다, 주어진 조건이 무엇을 정하고 무엇을 남기는지 밝히는 것이 더 완전한 분석이다.
</div>

## 4. 시험 및 검사

### A. 유리함수 재구성 검산

1. 수직 점근선 $$x = 1$$, 수평 점근선 $$y = 1$$, $$x$$ 절편 3인 그래프에서 $$\frac{x-3}{x-1}$$ 을 얻는다.
2. 상수는 이미 수평 점근선이 정했음을 확인한다.
3. 그래프에서 해석한 $$y$$ 절편 3과 $$f(0) = \frac{-3}{-1} = 3$$ 을 비교한다.
4. 판정: 두 값이 일치한다. 이 비교는 독립적인 검산이다.

### B. 다항함수 재구성 검산

1. $$x = \pm 1, \pm 2$$ 에서 모두 관통하고 $$y$$ 절편이 $$-4$$ 인 4차 다항식을 $$a(x+2)(x+1)(x-1)(x-2)$$ 로 둔다.
2. $$f(0) = 4a$$ 에서 $$a = -1$$ 이다.
3. 음수 $$a$$ 가 양 끝이 모두 내려가는 모양과 맞는지 확인한다.
4. $$f(1.5) = -(3.5)(2.5)(0.5)(-0.5) = \tfrac{35}{16} \approx 2.19$$ 를 계산한다.
5. 판정: 이 값이 $$x = 1$$ 과 $$x = 2$$ 사이의 작은 언덕 높이와 맞으면 합격이다.

## 5. 종료

### A. 결과 정리

1. 다항함수와 유리함수의 개형은 다섯 가지 대수적 특성으로 결정한다.
   1. 양 끝에서의 극한(3.B).
   2. 영점과 중복도(3.C).
   3. 불연속점: 구멍과 수직 점근선(3.D, 3.H).
   4. 절편(3.E).
   5. 부호 변화(3.F, 3.G).
2. 다섯 가지 특성 중 하나라도 빠진 개형은 근거가 불완전하다.
3. 개형을 그리는 방향이든 함수식을 재구성하는 방향이든 특성을 구하는 순서는 같다(3.K).
