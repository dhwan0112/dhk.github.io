조립제법 아랫줄의 숫자는 뜻이 두 개다. 몫의 계수이면서, 동시에 $$P(c)$$를 Horner 방법으로 계산할 때 차례로 나오는 중간값이다. 그래서 마지막 칸은 나머지이면서 $$P(c)$$이고, 나머지정리는 이 한 줄로 증명이 끝난다. 고등학생 과외를 하면서 보면 조립제법을 절차로만 외운 학생은 $$(x-c)$$ 꼴 문제는 빠르게 풀지만 $$2x-1$$로 나누거나 이차식으로 나누는 문제에서 멈춘다. 절차가 어디서 왔는지 모르니 변형할 수가 없어서다. 아래는 그 출처를 긴 나눗셈에서부터 다시 따라간 기록이다.

## 긴 나눗셈에서 지울 수 있는 것을 지우면

$$P(x) = 2x^3 - 5x^2 + 3x - 7$$을 $$x-2$$로 긴 나눗셈(long division)하면 세 단계가 나온다.

| 단계 | 몫에 붙는 항 | 빼는 식 | 빼고 남는 다음 계수 |
|---|---|---|---|
| 1 | $$2x^2$$ | $$2x^3 - 4x^2$$ | $$-5 - (-4) = -1$$ |
| 2 | $$-x$$ | $$-x^2 + 2x$$ | $$3 - (-2) = 1$$ |
| 3 | $$1$$ | $$x - 2$$ | $$-7 - (-2) = -5$$ |

빼는 식의 최고차항은 매번 지워지도록 고른 것이니 적을 필요가 없다. 남는 건 둘째 항뿐인데, 그건 늘 "방금 구한 몫의 계수 × (−2)"다. 이걸 빼는 건 "몫의 계수 × 2"를 더하는 것과 같다. 변수 $$x$$를 지우고, 지워질 항을 지우고, 빼기를 더하기로 바꾸면 남는 게 조립제법(synthetic division)이다.

| | 2 | −5 | 3 | −7 |
|---|---|---|---|---|
| $$c = 2$$ | | 4 | −2 | 2 |
| | 2 | −1 | 1 | −5 |

몫은 $$2x^2 - x + 1$$, 나머지는 $$-5$$. 즉 조립제법은 다른 알고리즘이 아니라 긴 나눗셈을 압축해서 적는 방법이다.

일반형으로 쓰면 더 분명하다. $$P(x) = a_n x^n + \cdots + a_1 x + a_0$$을 $$x - c$$로 나눈 몫을 $$Q(x) = b_{n-1}x^{n-1} + \cdots + b_0$$, 나머지를 $$R$$이라 하고

$$
P(x) = (x - c)\,Q(x) + R
$$

의 양변에서 $$x^k$$의 계수를 맞추면 $$a_n = b_{n-1}$$, $$a_k = b_{k-1} - c\,b_k$$, $$a_0 = R - c\,b_0$$이다. 정리하면

$$
b_{n-1} = a_n, \qquad b_{k-1} = a_k + c\,b_k, \qquad R = a_0 + c\,b_0
$$

"내리고, $$c$$를 곱해서 다음 칸에 더한다"는 절차가 이 점화식 그대로다. 학생들이 자주 틀리는 두 가지도 여기서 설명된다. 빠진 차수에 0을 넣어야 하는 건 점화식이 차수마다 칸을 하나씩 쓰기 때문이고, $$x + 3$$으로 나눌 때 $$c = -3$$인 건 $$c$$가 나누는 식의 상수항이 아니라 그 식을 0으로 만드는 값이기 때문이다.

## 같은 한 줄이 Horner 방법이다

같은 다항식을 안쪽부터 묶으면

$$
P(x) = \big((2x - 5)x + 3\big)x - 7
$$

이 되고, $$x = 2$$를 넣어 안쪽부터 계산하면 $$2 \to 2\cdot 2 - 5 = -1 \to (-1)\cdot 2 + 3 = 1 \to 1\cdot 2 - 7 = -5$$. 조립제법 아랫줄 $$2, -1, 1, -5$$와 숫자까지 같다. 이렇게 묶어서 계산하는 걸 Horner 방법(Horner's method)이라 부른다. 두 계산이 같다는 건 앞의 점화식 $$b_{k-1} = a_k + c\,b_k$$가 "지금까지의 값에 $$c$$를 곱하고 다음 계수를 더한다"는 Horner의 한 걸음과 똑같다는 뜻이다.

그러면 마지막 칸은 한편으로 나머지 $$R$$이고, 다른 한편으로 $$P(c)$$다. 나머지정리(remainder theorem) $$R = P(c)$$는 $$P(x) = (x-c)Q(x) + R$$에 $$x = c$$를 넣어 증명하는 게 보통이지만, 조립제법을 알고 있으면 이미 눈앞에 있는 사실이다. 인수정리(factor theorem)도 마찬가지로, 마지막 칸이 0이면 $$x - c$$가 인수이고 그 앞의 숫자들이 남은 인수의 계수다. $$x^3 - 6x^2 + 11x - 6$$에 $$c = 1$$을 넣으면 아랫줄이 $$1, -5, 6, 0$$이므로 $$(x-1)(x^2 - 5x + 6) = (x-1)(x-2)(x-3)$$까지 한 번에 간다. 근을 찾을 때 조립제법이 대입보다 나은 이유가 이것이다. 확인과 동시에 차수가 하나 낮은 몫이 나온다.

Horner 형태의 실제 이득은 곱셈 수다. $$n$$차 다항식 하나의 값을 구할 때:

| 계산 방법 | 곱셈 횟수 | $$n = 4$$ |
|---|---|---|
| 각 항의 거듭제곱을 매번 새로 계산 | $$n(n+1)/2$$ | 10 |
| $$x^2, x^3, \ldots$$을 차례로 저장해 재사용 | $$2n - 1$$ | 7 |
| Horner | $$n$$ | 4 |

덧셈은 셋 다 $$n$$번이다. 손으로 할 때는 큰 거듭제곱을 안 써도 된다는 게 더 크다. $$P(x) = 2x^4 - 3x^3 + 5x - 7$$에서 $$P(3)$$을 구하면 $$3^4 = 81$$ 같은 수 없이 $$2 \to 3 \to 9 \to 32 \to 89$$로 끝나고, 곁다리로 몫 $$2x^3 + 3x^2 + 9x + 32$$까지 얻는다. 코드로는 몇 줄이다.

```python
def horner(coeffs, c):
    """coeffs from the highest degree down (zeros included).
    Returns (quotient coefficients, remainder) of division by (x - c)."""
    row = [coeffs[0]]
    for a in coeffs[1:]:
        row.append(a + c * row[-1])
    return row[:-1], row[-1]

horner([2, -3, 0, 5, -7], 3)   # -> ([2, 3, 9, 32], 89)
```

## 한 번 더 나누면

몫 $$Q$$를 다시 $$x - c$$로 조립제법하면 무엇이 나올까. $$P(x) = (x-c)Q(x) + R$$을 미분하면 $$P'(x) = Q(x) + (x-c)Q'(x)$$이므로 $$Q(c) = P'(c)$$다. 앞의 예에서 $$Q(x) = 2x^2 - x + 1$$을 $$c = 2$$로 나누면 아랫줄이 $$2, 3, 7$$이고, 실제로 $$P'(x) = 6x^2 - 10x + 3$$에서 $$P'(2) = 7$$이다. 이걸 끝까지 반복하면 나머지들이 차례로 $$-5, 7, 7$$, 마지막에 2가 남아서

$$
P(x) = 2(x-2)^3 + 7(x-2)^2 + 7(x-2) - 5
$$

즉 $$x = 2$$ 중심의 전개가 나온다. 전개해 보면 원래 식으로 돌아온다. 미분을 배운 학생에게는 조립제법이 단순한 나눗셈 요령이 아니라는 걸 보여 주기 좋은 예다.

## (ax − b)로 나눌 때

$$2x - 1$$처럼 최고차 계수가 1이 아니면 $$ax - b = a\left(x - \tfrac{b}{a}\right)$$로 본다.

$$
P(x) = \left(x - \tfrac{b}{a}\right)\tilde{Q}(x) + R = (ax - b)\cdot\frac{\tilde{Q}(x)}{a} + R
$$

그러니 $$c = b/a$$로 조립제법을 한 뒤 몫만 $$a$$로 나누고, 나머지는 그대로 둔다. 과외에서 가장 자주 보는 실수가 나머지까지 $$a$$로 나누는 것이다. $$6x^3 - 7x^2 + 4x + 1$$을 $$2x - 1$$로 나누면 $$c = 1/2$$일 때 아랫줄이 $$6, -4, 2, 2$$다. 몫은 $$(6x^2 - 4x + 2)/2 = 3x^2 - 2x + 1$$, 나머지는 2다. 나머지를 1로 적으면 틀린다. 나머지정리로 바로 확인된다. $$P(1/2) = \tfrac{6}{8} - \tfrac{7}{4} + 2 + 1 = 2$$이고, $$x = 1/2$$을 넣으면 $$ax - b$$가 0이 되므로 $$a$$를 어떻게 묶든 나머지는 $$P(b/a)$$ 그대로여야 한다.

## 이차식으로 나눌 때

같은 계수 맞추기를 $$x^2 - px - q$$에 대해 하면 조립제법이 두 줄짜리가 된다. $$P(x) = (x^2 - px - q)Q(x) + rx + s$$에서 $$x^k$$의 계수를 비교하면

$$
b_{k-2} = a_k + p\,b_{k-1} + q\,b_k, \qquad r = a_1 + p\,b_0 + q\,b_1, \qquad s = a_0 + q\,b_0
$$

(범위를 넘는 $$b$$는 0). 일차식일 때는 "앞 칸 × $$c$$"를 더했다면, 이번엔 "앞 칸 × $$p$$"와 "두 칸 앞 × $$q$$"를 더한다. 나머지가 두 항이라 마지막 두 칸만 규칙이 조금 다르다.

$$x^4 - 3x^2 + 1$$을 $$x^2 + x - 1$$로 나누면 $$p = -1$$, $$q = 1$$이다. 계수 $$1, 0, -3, 0, 1$$에서 $$b_2 = 1$$, $$b_1 = 0 + (-1)(1) = -1$$, $$b_0 = -3 + (-1)(-1) + (1)(1) = -1$$, $$r = 0 + (-1)(-1) + (1)(-1) = 0$$, $$s = 1 + (1)(-1) = 0$$. 나머지가 0이므로

$$
x^4 - 3x^2 + 1 = (x^2 + x - 1)(x^2 - x - 1)
$$

로 인수분해된다. 긴 나눗셈으로 해도 세 번째 단계에서 딱 떨어진다.

최고차 계수가 1이 아니면 일차식과 같은 방법으로 처리한다. $$6x^4 + 7x^3 - 14x^2 + 15x - 18$$을 $$2x^2 + 3x - 2 = 2\left(x^2 + \tfrac{3}{2}x - 1\right)$$로 나누면 $$p = -3/2$$, $$q = 1$$이고

$$
b_2 = 6,\quad b_1 = 7 - 9 = -2,\quad b_0 = -14 + 3 + 6 = -5,\quad r = 15 + \tfrac{15}{2} - 2 = \tfrac{41}{2},\quad s = -18 - 5 = -23
$$

몫은 $$(6x^2 - 2x - 5)/2 = 3x^2 - x - \tfrac{5}{2}$$, 나머지는 $$\tfrac{41}{2}x - 23$$으로 긴 나눗셈 결과와 같다.

솔직히 이차식으로 나눌 때 이 두 줄짜리 표가 계수만 쓰는 긴 나눗셈보다 손으로 크게 빠르지는 않다. 이 표를 가르치는 건 속도보다 구조를 보여 주기 위해서다. 조립제법, 긴 나눗셈, Horner 방법이 모두 $$P = BQ + R$$의 계수를 위에서부터 맞춰 내려가는 같은 계산이라는 걸 한 번 보고 나면, 나누는 식이 $$2x - 1$$이든 이차식이든 학생이 절차를 새로 외울 필요가 없다. 막히면 계수 비교로 돌아가서 점화식을 다시 세우면 된다. 검산은 어느 방법으로 풀었든 $$B \cdot Q + R$$을 전개해 원래 식이 나오는지, 그리고 $$R$$의 차수가 $$B$$보다 낮은지 보면 된다.
